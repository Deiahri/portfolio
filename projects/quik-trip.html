QuikTrip

Currently in Development

Goal

Given a time range, acquire the best time- the departure time that will result in the least travel time- to travel to a given destination or route. (This is the second generation of BTTL- a previous project)

Implementation

Used React.js and Material UI to implement the user interface, Node.js and Firebase to implement the backend, and Google Map APIs to perform route calculations.
